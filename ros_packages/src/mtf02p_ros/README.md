# mtf02p_ros

ROS2 пакет для публикации одометрии на основе данных с MTF-02P оптического датчика потока.

## Описание

Этот пакет читает данные с датчика MTF-02P через UART, применяет фильтрацию Калмана для сглаживания скорости потока и интегрирует скорость для получения позиции. Одометрия публикуется в топик `/odom` с трансформацией `odom -> odom_link`.

Пакет реализован на C++ и использует POSIX API для работы с последовательным портом.

## Зависимости

- ROS2 Humble (или более новая версия)
- C++17 компилятор
- Стандартные POSIX библиотеки (termios, fcntl, unistd)

## Установка

1. Убедитесь, что пакет находится в `ros_packages/src/mtf02p_ros/`

2. Установите зависимости:
```bash
rosdep install --from-paths src --ignore-src -r -y
```

3. Соберите пакет:
```bash
cd ros_packages
colcon build --packages-select mtf02p_ros
source install/setup.bash
```

## Использование

### Запуск узла

```bash
ros2 launch mtf02p_ros mtf02p_odom.launch.py
```

### Параметры запуска

- `uart_port` (default: `/dev/ttyS3`) - путь к UART устройству (UART3_M2 на Orange Pi 5 Pro)
- `uart_baudrate` (default: `115200`) - скорость передачи данных
- `odom_frame_id` (default: `odom`) - родительский frame для одометрии
- `child_frame_id` (default: `odom_link`) - дочерний frame для одометрии
- `publish_tf` (default: `true`) - публиковать ли трансформацию
- `publish_rate` (default: `50.0`) - частота публикации одометрии (Hz)
- `kalman_process_variance` (default: `0.01`) - ковариация процесса для фильтра Калмана
- `kalman_measurement_variance` (default: `0.1`) - ковариация измерения для фильтра Калмана
- `max_velocity_change` (default: `50.0`) - максимальное изменение скорости за шаг для фильтрации выбросов (см/с)
- `dead_zone_threshold` (default: `1.0`) - порог dead zone для фильтрации малых скоростей (см/с)
- `min_dt` (default: `0.001`) - минимальный временной интервал между измерениями (секунды)
- `max_dt` (default: `2.0`) - максимальный временной интервал между измерениями (секунды)

### Пример запуска с параметрами

```bash
ros2 launch mtf02p_ros mtf02p_odom.launch.py \
  uart_port:=/dev/ttyS3 \
  uart_baudrate:=115200 \
  publish_rate:=50.0
```

## Структура пакета

- `src/mtf02p_odom_node.cpp` - основной ROS2 узел
- `src/uart_reader.cpp` - класс для чтения данных с UART
- `src/micolink_parser.cpp` - парсер протокола Micolink
- `src/kalman_filter.cpp` - фильтр Калмана для сглаживания скорости
- `include/mtf02p_ros/` - заголовочные файлы

## Топики

- `/odom` (nav_msgs/msg/Odometry) - публикация одометрии

## TF трансформации

- `odom -> odom_link` - трансформация одометрии (публикуется если `publish_tf=true`)

## Структура фреймов

Пакет публикует трансформацию `odom -> odom_link`, которая интегрируется с другими трансформациями в системе:
- `odom -> odom_link` (публикуется этим пакетом)
- `odom_link -> base_link` (публикуется другими узлами, например `imu_transform_publisher`)
- `base_link -> imu_link` (статическая трансформация)

## Особенности реализации

- Использует системное время датчика (`system_time`) для точного вычисления временных интервалов
- Z-ось (высота) берется напрямую из данных дальномера без фильтрации
- X и Y позиции вычисляются интегрированием отфильтрованной скорости потока
- Применяется фильтрация по качеству потока, статусу и временным интервалам
- Dead zone фильтрация для игнорирования малых скоростей
- Преобразование осей координат датчика в стандарт ROS2 (REP 103):
  - ROS2 X (вперед) = -flow_vel_y датчика
  - ROS2 Y (влево) = -flow_vel_x датчика
  - ROS2 Z (вверх) = distance датчика (в метрах)

## Аппаратная поддержка

Пакет разработан для работы с MTF-02P на Orange Pi 5 Pro через UART3_M2 (`/dev/ttyS3`).
