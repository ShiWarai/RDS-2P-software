# Panda assets (`data/faces`, `data/sounds`)

При необходимости замените placeholder-файлы реальными ассетами:

- Звуки: из `rtulab_feetech/sound/` — `idle1.wav`, `idle6.wav`, `idle3.wav`, `death1.wav`, `bleat2.wav`, `bleat3.wav`.
- Морды: PNG **280×240** (можно любое разрешение — узел масштабирует). В **`data/faces/`** лежит заглушка `smileW.png` под `commands.yaml`; замените своими файлами.

После сборки файлы ставятся в `share/rds_2p_commands/data/`.
