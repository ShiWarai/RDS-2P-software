# MPU6500 ROS2 Package

ROS2 пакет для работы с IMU сенсором MPU6500. Включает два узла:
1. **Основной узел** - использует DMP (Digital Motion Processor) для получения квантарионов
2. **Простой узел** - прямое управление I2C с комплементарным фильтром

## Особенности

- **Основной узел**: Использование DMP для получения квантарионов
- **Простой узел**: Прямое управление I2C, комплементарный фильтр
- Поддержка I2C интерфейса
- Публикация данных в стандартный топик `/imu`
- Настраиваемая частота публикации
- Унифицированные параметры для обоих узлов

## Зависимости

- ROS2 (Humble или новее)
- `sensor_msgs`
- `geometry_msgs`
- `std_msgs`
- `rclcpp`
- `ament_cmake`

## Сборка

```bash
# В рабочем пространстве ROS2
cd ros_packages/src/mpu6500_ros
colcon build --packages-select mpu6500_ros
```

## Запуск

### Основной узел (с DMP)

#### Базовый запуск
```bash
ros2 launch mpu6500_ros mpu6500_imu.launch.py
```

#### С параметрами
```bash
ros2 launch mpu6500_ros mpu6500_imu.launch.py \
    address:=0 \
    publish_rate:=50.0 \
    frame_id:=base_link \
    enable_calibration:=true
```

### Простой узел (прямое I2C управление)

#### Базовый запуск
```bash
ros2 launch mpu6500_ros mpu6500_simple_imu.launch.py
```

#### С параметрами
```bash
ros2 launch mpu6500_ros mpu6500_simple_imu.launch.py \
    address:=0 \
    publish_rate:=100.0 \
    frame_id:=imu_link \
    enable_calibration:=true
```

### Запуск без калибровки
```bash
ros2 launch mpu6500_ros mpu6500_simple_imu.launch.py \
    address:=0 \
    enable_calibration:=false
```

## Параметры

Оба узла поддерживают одинаковый набор параметров:

| Параметр | По умолчанию | Описание |
|----------|---------------|----------|
| `address` | `0` | Адрес MPU6500: `0` (I2C-1) или `1` (I2C-0) |
| `publish_rate` | `100.0` | Частота публикации в Hz |
| `frame_id` | `imu_link` | Frame ID для сообщений IMU |
| `enable_calibration` | `true` | Включить автоматическую калибровку при запуске |

## Топики

### Публикуемые
- `/imu` - данные IMU (sensor_msgs/Imu)
  - `orientation` - квантарион ориентации
  - `angular_velocity` - угловая скорость (рад/с)
  - `linear_acceleration` - линейное ускорение (м/с²)

## Подключение

### I2C (поддерживается обоими узлами)
- SCL: GPIO3
- SDA: GPIO2
- INT: GPIO17 (не используется в простом узле)

**Примечание**: Простой узел использует только I2C интерфейс

## Алгоритмы обработки данных

### Основной узел (DMP)
Использует DMP (Digital Motion Processor) MPU6500 для:
- Получения квантарионов ориентации
- Фильтрации данных акселерометра и гироскопа
- Автоматической калибровки
- Стабилизации данных

### Простой узел (Комплементарный фильтр)
Использует собственный алгоритм:
- Прямое чтение данных акселерометра и гироскопа
- Комплементарный фильтр для объединения данных
- Автоматическая калибровка при запуске
- Коэффициент фильтрации: 0.98 (гироскоп) + 0.02 (акселерометр)

## Автоматическая калибровка

При запуске узла (если `enable_calibration=true`) выполняется автоматическая калибровка:

1. **Подготовка**: Устройство должно быть неподвижно и расположено горизонтально
2. **Процесс**: Считывается 100 образцов данных для вычисления смещений
3. **Результат**: Устанавливаются смещения для акселерометра и гироскопа
4. **Время**: Калибровка занимает примерно 1-2 секунды

**Важно**: Во время калибровки устройство должно оставаться неподвижным!

### Отключение калибровки
```bash
ros2 launch mpu6500_ros mpu6500_simple_imu.launch.py enable_calibration:=false
```

## Устранение неполадок

### Основной узел
1. **Ошибка инициализации**: Проверьте подключение и права доступа к GPIO
2. **Нет данных**: Убедитесь, что DMP инициализирован корректно
3. **Неточные данные**: Выполните калибровку сенсора

### Простой узел
1. **Ошибка "Failed to open I2C bus"**: Проверьте права доступа к `/dev/i2c-1` или `/dev/i2c-0`
2. **Нет данных**: Убедитесь, что MPU6500 подключен и адрес правильный
3. **Неточные показания**: Убедитесь, что устройство откалибровано и неподвижно во время калибровки

### Общие проблемы
- **Неправильный адрес I2C**: Используйте `address:=0` для I2C-1 или `address:=1` для I2C-0
- **Низкая частота**: Увеличьте `publish_rate` для более плавных данных
- **Проблемы с калибровкой**: Отключите калибровку с `enable_calibration:=false`
