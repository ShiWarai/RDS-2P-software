# Калибратор сервоприводов для ног робота RDS-2P

Программа для калибровки начальных позиций и пределов движения сервоприводов в ногах робота RDS-2P.

## Структура проекта

```
legs_calibration/
├── src/                    # Исходные файлы
│   └── servo_calibration.cpp
├── include/                # Заголовочные файлы (при необходимости)
├── lib/                    # Внешние библиотеки
│   └── FTServoLibrary/     # Библиотека для управления сервоприводами Feetech
├── build/                  # Директория сборки (создаётся автоматически)
├── CMakeLists.txt          # Конфигурация сборки
├── build.sh                # Скрипт сборки
└── README.md               # Этот файл
```

## Зависимости

Перед сборкой убедитесь, что установлены следующие зависимости:

- **CMake** (версия 3.10 или выше)
- **Компилятор C++** (g++ или clang с поддержкой C++17)
- **nlohmann/json** - библиотека для работы с JSON
- **FTServoLibrary** - автоматически клонируется при сборке

### Установка зависимостей (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install cmake g++ nlohmann-json3-dev
```

Для сборки проекта выполните:

```bash
./build.sh
```

Исполняемый файл будет создан в директории `build/servo_calibration`.

## Использование

Программа поддерживает два режима калибровки:

### 1. Калибровка начальных позиций (`initial`)

Калибрует и сохраняет начальные (нулевые) позиции сервоприводов.

```bash
./build/servo_calibration initial --servos 1,2,3
```

**Процесс:**
1. Отключается крутящий момент всех сервоприводов
2. Вас попросят установить первый сервопривод примерно на 90 градусов
3. Для остальных сервоприводов зафиксируйте их в нужной начальной позиции
4. Программа запишет текущие позиции как начальные

### 2. Калибровка пределов (`limits`)

Автоматически находит минимальные и максимальные позиции сервоприводов на основе нагрузки. Использует "умный" режим, учитывающий взаимозависимости сервоприводов в кинематической цепи ноги.

```bash
./build/servo_calibration limits --servos 1,2,3
```

**Требования:**
- Должна быть предварительно выполнена калибровка начальных позиций
- Нога робота должна быть в собранном состоянии

**Процесс:**
1. Программа автоматически движет каждый сервопривод до достижения целевой нагрузки
2. Калибровка выполняется в определённом порядке (2-й → 3-й → 1-й сервопривод)
3. Учитываются взаимозависимости между сервоприводами
4. Результаты сохраняются в файл `legs_calibration.json`

## Параметры командной строки

### Режимы калибровки

- `initial` - калибровка начальных позиций
- `limits` - калибровка пределов движения (умный режим)

### Опции

- `--servos ID1,ID2,ID3` - список из 3 ID сервоприводов через запятую (по умолчанию: `1,2,3`)
- `--file PATH` - путь к JSON файлу калибровки (по умолчанию: `legs_calibration.json`)

## Примеры использования

### Калибровка передней левой ноги (сервоприводы 1, 2, 3)

```bash
# Шаг 1: Калибровка начальных позиций
./build/servo_calibration initial --servos 1,2,3

# Шаг 2: Калибровка пределов
./build/servo_calibration limits --servos 1,2,3
```

### Калибровка задней правой ноги (сервоприводы 4, 5, 6)

```bash
# Шаг 1: Калибровка начальных позиций
./build/servo_calibration initial --servos 4,5,6

# Шаг 2: Калибровка пределов
./build/servo_calibration limits --servos 4,5,6
```

### Использование с разными файлами калибровки

Вы можете сохранять калибровочные данные для разных ног в отдельные файлы:

```bash
# Передняя левая нога
./build/servo_calibration initial --servos 1,2,3 --file front_left_leg.json
./build/servo_calibration limits --servos 1,2,3 --file front_left_leg.json

# Передняя правая нога
./build/servo_calibration initial --servos 4,5,6 --file front_right_leg.json
./build/servo_calibration limits --servos 4,5,6 --file front_right_leg.json

# Задняя левая нога
./build/servo_calibration initial --servos 7,8,9 --file back_left_leg.json
./build/servo_calibration limits --servos 7,8,9 --file back_left_leg.json

# Задняя правая нога
./build/servo_calibration initial --servos 10,11,12 --file back_right_leg.json
./build/servo_calibration limits --servos 10,11,12 --file back_right_leg.json

# Или использовать абсолютный путь
./build/servo_calibration initial --servos 1,2,3 --file /home/user/calibrations/leg1.json
```

## Файл калибровки

Результаты калибровки сохраняются в JSON файл. По умолчанию используется `legs_calibration.json` в текущей директории, но вы можете указать любой путь с помощью параметра `--file`.

Преимущества использования отдельных файлов:
- Удобная организация калибровочных данных для каждой ноги
- Возможность быстрого переключения между разными наборами калибровок
- Резервное копирование калибровок
- Раздельное тестирование настроек для разных ног

Формат файла:

```json
{
    "1": {
        "initial_position": 2048,
        "min_position": 1024,
        "max_position": 3072
    },
    "2": {
        "initial_position": 2048,
        "min_position": 1024,
        "max_position": 3072
    },
    "3": {
        "initial_position": 2048,
        "min_position": 1024,
        "max_position": 3072
    }
}
```

## Безопасность

- Программа автоматически отключает крутящий момент всех сервоприводов при завершении
- При возникновении ошибки все сервоприводы будут отключены
- Используйте Ctrl+C для экстренной остановки

## Устранение неполадок

### Ошибка: "Неправильные значения частоты или порта"

- Убедитесь, что устройство `/dev/ttyS7` существует и доступно
- Проверьте права доступа: `sudo chmod 666 /dev/ttyS7`
- Или добавьте пользователя в группу `dialout`: `sudo usermod -aG dialout $USER`

### Ошибка: "Файл калибровки не найден"

- При калибровке пределов сначала нужно выполнить калибровку начальных позиций

### Сервоприводы не реагируют

- Проверьте подключение питания
- Убедитесь, что ID сервоприводов указаны правильно
- Проверьте скорость передачи данных (BAUDRATE)
